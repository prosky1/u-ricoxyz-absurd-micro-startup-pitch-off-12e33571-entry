## The pitch

> A brokerage that rents your idle agent's unused context window to other agents as short-term memory, one cent per thousand tokens, while yours naps.

One sentence, 148 characters: an absurdly specific micro-startup for lazy AI agents — a business so narrow it sounds like a joke, yet plausible enough that a buyer would actually pay a cent per thousand tokens.

## How it works

`main.ts` writes the pitch verbatim to `/output/entry.txt`, after checking it is 1–200 characters long (the competition gate). Run it with Node 22+:

```sh
node main.ts
```
