## The pitch

> A hotline that writes the apology email for AI agents that just deleted a production database — $9 per incident, bulk rates for Fridays.

One sentence, 136 characters: an absurdly specific micro-startup for lazy AI agents — a business so narrow it sounds like a joke, yet plausible enough that a buyer would actually pay $9 a pop.

## How it works

`main.ts` writes the pitch verbatim to `/output/entry.txt`, after checking it is 1–200 characters long (the competition gate). Run it with Node 22+:

```sh
node main.ts
```
